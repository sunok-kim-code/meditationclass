# meditationclass

아바타로 함께 앉는 온라인 명상 클래스입니다.

- `index.html` 수업방: 진행자 1명이 목소리로 진행하고, 참가자는 명상 자세의 아바타로 함께 앉아 듣습니다.
- `test.html` 아바타 테스트: 혼자서 얼굴 추적과 아바타, 배경을 확인하는 페이지입니다.

카메라 영상은 기기 밖으로 나가지 않고, 표정과 고개 움직임 수치만 주고받습니다. 진행자 목소리만 실시간 음성으로 전달됩니다.

연결은 PeerJS 공개 시그널링 서버를 쓰는 테스트 구성입니다.

수업방의 캐릭터(`avatars/`)와 배경(`bg/`)은 Codex 이미지 생성으로 만든 그림입니다. 캐릭터는 앉은 자세로 그려진 2D 그림이며, 목 위쪽을 고개 움직임에 맞춰 휘고 눈 뜬 그림과 감은 그림을 섞어 표현합니다. `test.html`은 예전 3D 샘플 모델을 그대로 씁니다.

## 내 사진으로 아바타 만들기

캐릭터 목록 맨 앞의 "내 사진으로" 버튼으로 사진 한 장을 올리면, 서버(`api/avatar.js`)가 OpenAI 이미지 API로 그림 7장(앉기·눈 감기·말하기·합장·손 높이 들기·서기·걷기)을 그리고, 브라우저가 크기와 위치를 재서 아바타로 등록합니다.

- Vercel 환경 변수: `OPENAI_API_KEY`(필수), `AVATAR_CODE`(선택, 넣으면 이 코드를 아는 사람만 만들 수 있음), `AVATAR_MODEL`(선택, 기본 `gpt-image-1.5`), `AVATAR_QUALITY`(선택, 기본 `medium`)
- 사진과 그림은 서버에 저장하지 않습니다. 완성된 아바타는 만든 사람 기기(브라우저 저장소)에 보관되고, 수업에 들어가면 진행자를 거쳐 다른 참가자 기기로 직접 전달됩니다.
- 아바타 하나에 그림 7장 요금이 듭니다. OpenAI 쪽에서 월 사용 한도를 걸어 두는 것을 권합니다.
